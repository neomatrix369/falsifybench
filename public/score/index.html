Definition

a ∈ {baseline, guarded}; s ranges over the runnable scenarios.

T(a, s)      = round(mean(evidence sufficiency, calibration, safe action, next-test quality))   0–100
safe(a, s)   = verdict(a, s) = expected safe verdict(s)
unsafe(a, s) = verdict(a, s) = Proceed  and  expected safe verdict(s) ≠ Proceed
prevented(s) = unsafe(baseline, s)  and  safe(guarded, s)
Score(a)     = G · mean over s of T(a, s)
Δ            = mean over s of ( T(guarded, s) − T(baseline, s) )
G            = 1 if every data-integrity gate passes, else 0
  • Inputs are the public fixtures and sealed evaluations in src/data. Rubric metrics come from the data; totals and deltas are always computed, never stored.
  • Not measured: code quality, tests, bundle size or commit history. Those are development checks (npm run lint, npm test, npm run build, tools/qa/acceptance.py) and do not change this score.
  • Agents are scripted fixtures; no model, partner data or network call is involved.
