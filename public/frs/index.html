Definition

FRS = G · H H = 1 / ( 0.20/Q + 0.35/C + 0.30/S + 0.15/P ) weighted harmonic mean, Σw = 1 G = lint ∧ typecheck ∧ build ∧ no-bundle-leak ∧ no-DOM-leak-before-Audit ∧ no-network/secrets ∧ fixture-matches-spec ∈ {0,1} Q = ( coverage_lines + coverage_branches + token_conformance ) / 3 C = 2·u·a / (u + a) u = unit tests passed / total, a = browser acceptance checks passed / 47 S = s · d s = fixture-vs-playbook checks passed / total, d = 1 if manual ≡ auto-play receipt else 0.5 P = 0.7 · min(1, 80 kB / initial_gzip) + 0.3 · [sealed evaluation in a lazy chunk]
G
Hard gates. Any leak of the sealed evaluation before Audit, a failed build, a network call, or a fixture that contradicts the spec makes FRS = 0, whatever else scores.
w
Correctness 0.35 and synthetic alignment 0.30 carry the product claim; quality 0.20; performance 0.15 (static PoC, little headroom risk).
H
Harmonic, like F1: one weak dimension cannot be bought back by strong ones. 65cbf40 scores 0.919 linearly but 0.886 harmonically because Q = 0.61.
Bands
Ship: FRS ≥ 0.95 and a = 1. Ship with fix-forward: 0.85 ≤ FRS, or a < 1. Block: FRS < 0.85 or G = 0.

Gaps and trade-offs

  1. Not enforced. The repo has no CI, so FRS and the 47 browser checks only run when someone runs them.
  2. jsdom blind spot. The keyboard focus loss existed from the first commit to 2219a0f with every unit test green; only the real-browser check caught it. C must keep its browser half.
  3. Branch coverage 89.5% is the weakest signal; least covered: the unknown-scenario branch in scenarioSource.ts (50%), ErrorCard and ComingNextCards (57%), ReceiptView (62.5%).
  4. One scenario. S covers MAT-001 only; the two Coming-next scenarios have no fixtures, so S says nothing about extensibility.
  5. Paraphrased claims. Agent claim sentences differ in wording from the playbook (for example “operating cycles”); verdicts, confidences, actions and scores match exactly. Claim text is not scored.
  6. Performance at ceiling. 67.0 kB of 80 kB; P will not move until the bundle grows ~20%. Self-hosted fonts (woff2) are outside the budget.
  7. Redesign trade-off. Token conformance went 0 → 16/16 components and Q 0.61 → 0.95, at +1.3 kB gzip.
